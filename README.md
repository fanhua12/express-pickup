# 取件码助手

自动从快递短信和通知里提取取件码，汇总成一个列表。纯本地，不联网，数据存在手机 SQLite 里。

## 功能

- 抓取快递短信和菜鸟/微信/快递App通知里的取件码
- 待取/已取/回收仓三个列表
- 新取件码弹通知提醒
- 自动去重
- 取件码规则可以自己改（正则）

## 安装

到 [Releases](../../releases) 下载 apk 装上就行，需要允许安装未知来源。

## 权限

装完打开 app，首页有引导卡，按提示开完 5 项权限：

1. 短信 - 读快递短信
2. 通知 - 弹提醒用
3. 通知使用权 - 抓菜鸟/微信/快递App通知，必开
4. 电池优化白名单 - 防止后台被杀
5. 自启动 - 各厂商路径不一样，大致在这些地方：
   - 小米：设置→应用设置→应用管理→自启动
   - 华为：设置→应用→应用启动管理→手动管理
   - OPPO：设置→应用管理→允许自启动
   - vivo：设置→应用与权限→权限管理→自启动

## 隐私

Manifest没声明INTERNET权限，系统层面就没法联网。数据只存本机，卸载就没了。

## 构建

JDK17 + Gradle 8.0 + AGP 8.1.0，SDK 34。

签名信息在 keystore.properties 里（没提交），没有的话构建出来是未签名的。
