# 取件码助手

自己写的一个小安卓工具。平时取快递老是要翻短信、翻通知找取件码，太麻烦，干脆做了个 app 让它自动把取件码扒出来，攒成一个列表。

纯本地跑，没申请联网权限，数据都存在手机本地的 SQLite 里，卸载就清干净了。

## 功能

- 抓快递短信、菜鸟/微信/快递 App 通知里的取件码
- 待取 / 已取 / 回收仓三个列表
- 截图识别取件码（离线中文 OCR，一次能选多张图）
- 菜鸟只发"快递到了"不发码的时候，建个「到件待查」，点一键查询直接跳到对应 App
- 新取件码弹通知提醒
- 自动去重
- 取件码规则可以自己改（正则），支持开关、排序、导入导出

## 安装

到 [Releases](../../releases) 下载 apk 装上就行，需要允许安装未知来源。

## 权限

装完打开 app，首页有引导卡，按提示开完 5 项权限：

1. 短信 - 读快递短信
2. 通知 - 弹提醒用
3. 通知使用权 - 抓菜鸟/微信/快递 App 通知，必开
4. 电池优化白名单 - 防止后台被杀
5. 自启动 - 各厂商路径不一样，大致在这些地方：
   - 小米：设置→应用设置→应用管理→自启动
   - 华为：设置→应用→应用启动管理→手动管理
   - OPPO：设置→应用管理→允许自启动
   - vivo：设置→应用与权限→权限管理→自启动

## 隐私

Manifest 没声明 INTERNET 权限，系统层面就没法联网。数据只存本机，卸载就没了。

## 构建

JDK17 + Gradle 8.0 + AGP 8.1.0，SDK 34。

签名信息在 keystore.properties 里（没提交），没有的话构建出来是未签名的。
