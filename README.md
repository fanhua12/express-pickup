# 取件码助手

纯本地的 Android 应用：自动从快递短信和 App 通知中提取取件码、驿站名称、快递公司，汇总成一个待取列表。

不联网、不上传、不需要服务器。所有数据只存在手机本机的 SQLite 里。

## 功能

- 自动抓取快递短信里的取件码
- 自动抓取菜鸟、微信、各快递 App 的通知
- 待取 / 已取两个列表，点一下切换状态
- 解析到新取件码时在通知栏大字提醒
- 同一取件码自动去重

## 工作原理

```
短信 SmsReceiver ─┐
                  ├─→ Ingestor ─→ PickupParser(正则) ─→ PickupDb(去重入库) ─→ LocalNotifier
通知 NotifyListener┘
```

`KeepAliveService` 以前台服务常驻，配合 `BootReceiver` 在开机后自动拉起。

## 安装

到 [Releases](../../releases) 下载最新版本的 `pickup-assistant-v1.x.apk`，传到手机上安装即可（需要允许"安装未知来源应用"）。

APK 签名证书 SHA-256：

```
4E:6A:F3:1C:C2:05:CE:24:E9:9C:D3:2E:70:5E:78:FB:20:87:8D:DF:B2:E5:36:71:33:E0:C5:0D:4D:7A:35:7F
```

## 安装后需要开的权限

打开应用后首页会显示一张权限引导卡，逐项点"去开启"即可。5 项全部开完，抓取才会稳定。

| # | 权限 | 作用 | 怎么开 |
|---|------|------|--------|
| 1 | 短信权限 | 读取快递到达短信 | 点"去开启"，系统弹窗允许 |
| 2 | 通知权限 | 有新取件码时提醒你 | 点"去开启"，系统弹窗允许 |
| 3 | 通知使用权限 | 抓取菜鸟 / 微信 / 快递 App 的通知，**必开** | 跳到系统"通知使用权"列表，找到"取件码助手"打开开关 |
| 4 | 电池优化白名单 | 防止后台被系统杀掉 | 点"去开启"，选择"允许" |
| 5 | 自启动管理 | 开机后自动运行 | 跳到厂商的自启动管理页，手动允许。部分机型路径较深，找不到就按第 3 步里提示的机型路径手动找 |

第 5 项各厂商差异最大，常见路径：

- 小米 / 红米：设置 → 应用设置 → 应用管理 → 取件码助手 → 自启动
- 华为 / 荣耀：设置 → 应用 → 应用启动管理 → 取件码助手 → 手动管理，三个开关全开
- OPPO / 一加 / realme：设置 → 应用管理 → 取件码助手 → 允许自启动 / 允许后台活动
- vivo / iQOO：设置 → 应用与权限 → 权限管理 → 自启动 → 取件码助手

## 隐私

`AndroidManifest.xml` 中不声明 `INTERNET` 权限，应用在系统层面就无法联网，不存在数据外传的可能。解析结果仅写入本机 SQLite，卸载应用即全部清除。

## 构建

需要 JDK 17、Gradle 8.0、AGP 8.1.0，以及 Android SDK（compileSdk 34）。

```
gradle assembleRelease
```

签名信息从项目根目录的 `keystore.properties` 读取（该文件含私钥，已在 `.gitignore` 中排除）：

```properties
storeFile=app/pickup-release.jks
storePassword=***
keyAlias=pickup
keyPassword=***
```

没有这个文件时 `assembleRelease` 仍可构建，但产物是未签名的。
